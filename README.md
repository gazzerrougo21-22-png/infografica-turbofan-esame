# infografica-turbofan-esame
Dai serbatoi d'ala al cuore della spinta: scopri come il combustibile viene pompato, filtrato e nebulizzato ad alta pressione. L'infografica illustra il percorso del carburante fino alla camera di combustione, dove la miscela con l'aria compressa accende il motore turbofan, generando la massima efficienza propulsiva.
